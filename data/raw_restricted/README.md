# Restricted Scopus metadata

Raw Scopus metadata files are **not redistributed** in this public repository because of database licensing restrictions.

To reproduce the full analysis, export the Scopus records using the search strategy described in `docs/scopus_search_strategy.md`, then place the following files in the working directory used by the notebook:

- `01_scopus_ai_food_metadata_raw_part01_2010_2015.csv`
- `01_scopus_ai_food_metadata_raw_part02_2016_2021.csv`
- `01_scopus_ai_food_metadata_raw_part03_2022_2023.csv`
- `01_scopus_ai_food_metadata_raw_part04_2024.csv`
- `01_scopus_ai_food_metadata_raw_part05_2025.csv`

The repository provides analysis code, public external indicators, documentation, and derived/aggregated outputs where possible.
