# Manuscript data availability statement

The processed datasets and Python codes used in this study are available in the GitHub repository: `https://github.com/paperlyj/AI-food-attention-need-mismatch`.

Raw Scopus metadata are not publicly redistributed because of database licensing restrictions; however, the Scopus search strategy, screening criteria, and preprocessing workflow are provided to support reproducibility. Public country-level indicators were obtained from World Bank, FAOSTAT, FAO, and UNEP sources, and source details are documented in the repository. Additional information is available from the corresponding author upon reasonable request.
