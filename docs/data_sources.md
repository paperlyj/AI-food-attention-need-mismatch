# Data sources

This project combines Scopus-indexed AI-food bibliometric metadata with external country-level indicators.

## Bibliometric metadata

- Source: Scopus
- Period: 2010–2025
- Raw Scopus CSV exports are not redistributed because of database licensing restrictions.
- Expected raw filenames are listed in `data/raw_restricted/README.md`.

## Public external indicators included in this repository

- World Bank population: `SP.POP.TOTL`
- World Bank GDP, current US$: `NY.GDP.MKTP.CD`
- World Bank R&D expenditure: `GB.XPD.RSDV.GD.ZS`
- World Bank/FAO prevalence of undernourishment: `SN.ITK.DEFC.ZS`
- World Bank/WHO child stunting: `SH.STA.STNT.ZS`
- World Bank/WHO adult obesity by sex: `SH.STA.OB18.FE.ZS`, `SH.STA.OB18.MA.ZS`
- UNEP Food Waste Index Report 2024
- FAOSTAT agrifood-system greenhouse gas emissions
- FAO cereal import dependency ratio
- World Bank country metadata: region and income group

External datasets remain subject to the terms of their original data providers.
