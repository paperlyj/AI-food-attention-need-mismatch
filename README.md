# Global mismatch between AI-food research attention and food-system need

This repository contains the Python workflow, public external indicators, documentation, and selected processed/aggregated data used for the manuscript:

**Global mismatch between AI-food research attention and food-system need**

## Repository contents

- `notebooks/AI_food_attention_need_mismatch_analysis.ipynb`: Python notebook for data processing, bibliometric text mining, country-level indicator integration, attention–need mismatch analysis, and visualization.
- `data/raw_public/`: publicly available external indicator files used in the analysis.
- `data/raw_restricted/`: notes on restricted Scopus metadata. Raw Scopus exports are not redistributed.
- `data/processed/`: selected processed and aggregated outputs that do not contain raw Scopus bibliographic records.
- `docs/`: data-source notes, Scopus search strategy description, data dictionary, and availability statement.
- `figures/`: candidate manuscript figures.

## Important note on Scopus data

Raw Scopus metadata are not included in this repository because of database licensing restrictions. To reproduce the full bibliometric workflow, users with appropriate Scopus access should export the raw records using the search strategy documented in `docs/scopus_search_strategy.md` and place the five Scopus CSV files in the expected working directory.

## Data availability

Processed/aggregated datasets and Python code are provided in this repository. Public external indicators were obtained from World Bank, FAOSTAT, FAO, and UNEP sources. Raw Scopus metadata are not publicly redistributed. See `docs/availability_statement.md` for the manuscript-ready data availability statement.

## Reproducibility

The analysis was conducted in Python. Required packages are listed in `requirements.txt`. Some notebook cells require the restricted Scopus export files to be present.
